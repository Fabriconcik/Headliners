# Руководство: игра без команд на ПК и решение ошибки PowerShell

В этом руководстве детально разобраны все вопросы:
1. **Почему возникла ошибка в PowerShell** и как запускать игру в 1 клик без терминала.
2. **Можно ли играть через Bluetooth или открывать сервер на планшете/телефоне хоста** (технические ограничения мобильных платформ: TCP, Bluetooth, WebRTC).
3. **Реальные решения:** как играть вообще без ПК (бесплатное облако в стиле Jackbox Games), как играть через 1 клик на ПК, или как запустить сервер на Android-планшете на природе.

---

## 1. Разбор ошибки `PSSecurityException` в PowerShell

В вашей системе при попытке выполнить `npm start` появилась ошибка:
```
npm : Невозможно загрузить файл C:\Program Files\nodejs\npm.ps1, так как выполнение сценариев отключено в этой системе.
+ FullyQualifiedErrorId : UnauthorizedAccess, PSSecurityException
```

### Почему это произошло?
По умолчанию в Windows PowerShell включена политика безопасности `Restricted`, которая блокирует запуск любых скриптов `.ps1`. При вводе `npm start` PowerShell находит файл `npm.ps1` и отказывается его выполнять.

### Как запустить сервер без ошибок (выберите любой удобный вариант):

- **Вариант А (Самый удобный — запуск в 1 клик):**  
  Дважды кликните по файлу **`start.bat`** в папке проекта.  
  Он запускается через стандартный командный интерпретатор Windows (`cmd.exe`), на который политика PowerShell вообще не распространяется. Скрипт сам проверит Node.js, установит библиотеки (если нужно), соберет проект, откроет браузер хоста и покажет Wi-Fi адреса для друзей.

- **Вариант Б (Ярлык на Рабочем столе):**  
  Дважды кликните по **`create-desktop-shortcut.bat`**. На вашем Рабочем столе появится ярлык «Live News Chaos». Вы сможете запускать игру в 1 клик прямо с Рабочего стола!

- **Вариант В (Прямо в VS Code без терминала):**  
  В VS Code нажмите сочетание клавиш **`Ctrl + Shift + B`** (или в верхнем меню выберите *Terminal -> Run Task... -> Запустить игру (1-Click)*). Игра запустится автоматически.

- **Вариант Г (Команда в терминале VS Code):**  
  Вместо `npm start` напишите:
  ```powershell
  npm.cmd start
  ```
  Или:
  ```powershell
  node dist/server/index.js
  ```
  Команда `npm.cmd` — это бинарный скрипт CMD, который PowerShell запускает без проверки политики скриптов `.ps1`.

- **Вариант Д (Разрешить выполнение скриптов навсегда):**  
  Запустите файл **`fix-powershell.bat`** (или введите в PowerShell команду: `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force`). Это навсегда снимет блокировку для вашего пользователя.

## 2. Можно ли сделать, чтобы сервер открывался на устройстве хоста или игроки связывались через Bluetooth / Wi-Fi без ПК?

Это частый и правильный вопрос. Давайте разберем, как устроены мобильные устройства и браузеры:

### 1. Почему нельзя сделать сервер прямо внутри мобильного браузера хоста?
- **Изоляция песочницы (Sandbox):** Браузеры на мобильных устройствах (Safari на iOS, Chrome на Android) работают в жестко изолированной песочнице операционной системы.
- **Запрет на прослушивание портов:** Браузеру запрещено открывать сетевые порты на входящие соединения (`server.listen(3000)`). Он может только *отправлять* запросы наружу, но не может принимать входящие соединения от других телефонов.

### 2. Почему нельзя связать игроков по Bluetooth через веб-страницу?
- **Ограничения Web Bluetooth API:** В стандарте браузеров Web Bluetooth работает **исключительно в роли клиента (Central)** — для подключения к часам, наушникам или фитнес-браслетам.
- Браузер **не может объявлять себя Bluetooth-сервером (Peripheral)** и передавать игровые данные другим смартфонам без нативного приложения, установленного из App Store / Google Play.
- Более того, на устройствах Apple (iPhone, iPad) в браузере Safari технология Web Bluetooth вообще заблокирована производителем из соображений безопасности.

### 3. Почему нельзя сделать P2P (WebRTC) совсем без сервера?
- Браузеры действительно умеют соединяться напрямую друг с другом по технологии WebRTC DataChannel (P2P).
- **Однако WebRTC требует сигнальный сервер (Signaling):** Чтобы два браузера нашли друг друга в сети, они обязаны обменяться сессионными ключами (SDP offer/answer) и кандидатами сетевого маршрута (ICE candidates).
- Без сигнального сервера в интернете игрокам пришлось бы вручную сканировать по 3–4 гигантских QR-кода с криптографическими ключами туда и обратно между каждым телефоном, что делает игру невозможной для компании.

## 3. Как устроены такие игры в мире (Jackbox, Gartic Phone, Kahoot) и 3 готовых решения

Все популярные пати-игры используют одну из трех проверенных архитектур:

### Решение 1 (Идеальное — вообще без ПК): Бесплатный облачный сервер (Jackbox-модель)

Сервер размещается один раз в облаке на бесплатном тарифе (**Render.com**, **Railway.app** или **Fly.io**). После этого **компьютер не нужен вообще**!

#### Как настроить за 3 минуты:
1. Загрузите файлы этого проекта в свой репозиторий на **GitHub** (репозиторий может быть приватным).
2. Зарегистрируйтесь на бесплатном хостинге [Render.com](https://render.com).
3. Нажмите кнопку **New +** → **Web Service** и выберите ваш GitHub-репозиторий.
4. Render автоматически увидит готовый файл конфигурации `render.yaml` из проекта.
   (Если спросит вручную: *Build Command:* `npm install && npm run build`, *Start Command:* `npm start`).
5. Нажмите **Create Web Service**. Через 2 минуты проект соберется, и вы получите персональный адрес:
   `https://vash-proekt.onrender.com`

#### Как играть:
- Ведущий открывает эту ссылку с **планшета, телевизора или телефона** и нажимает «Создать студию».
- На экране появляется код комнаты и QR-код.
- Все остальные игроки просто сканируют QR-код со своих смартфонов.
- **Никаких терминалов, никаких ПК** — игра работает круглосуточно из любой точки мира через Wi-Fi или мобильный 4G/LTE!

---

### Решение 2 (Для дома с друзьями): 1 клик на ПК через `start.bat`

Если вы находитесь дома в одной сети Wi-Fi:
1. Дважды кликните по **`start.bat`** (или ярлыку на рабочем столе).
2. На экране ПК автоматически откроется окно браузера: `http://localhost:3000`.
3. Нажмите «Создать студию».
4. В лобби нажмите кнопку **QR**. На экране появится QR-код с вашим реальным Wi-Fi адресом (например, `http://192.168.0.110:3000`).
   - *Примечание:* Если на вашем ПК активно несколько сетевых адаптеров (Wi-Fi, Ethernet, VPN), сервер автоматически выберет Wi-Fi сеть. При необходимости прямо в карточке QR-кода есть переключатель других IP-адресов.
5. Игроки, подключенные к тому же домашнему Wi-Fi роутеру, наводят камеры смартфонов на QR-код и сразу входят в игру.
6. Окно на ПК можно свернуть — управлять игрой можно прямо с телефонов.

---

### Решение 3 (Автономно на даче или на природе без интернета и без ПК)

Если вы собрались с друзьями там, где нет интернета и нет компьютера, сервером может стать обычный планшет или телефон на **Android**:
1. Установите на Android бесплатную консоль **Termux** (из каталога [F-Droid](https://f-droid.org/packages/com.termux/)).
2. В Termux выполните установку Node.js:
   ```bash
   pkg update && pkg install nodejs git
   ```
3. Скопируйте папку с проектом в память планшета и введите:
   ```bash
   node dist/server/index.js
   ```
4. Включите на планшете стандартную **«Точку доступа Wi-Fi»** (раздачу сети).
5. Все друзья подключаются своими телефонами к Wi-Fi сети этого планшета и переходят по IP-адресу, который покажет консоль Termux (обычно `http://192.168.43.1:3000`).
